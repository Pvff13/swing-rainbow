# Swing Rainbow

Recolors the swing trails of the dragon halberd, crystal halberd and scythe. Cosmetic only - it changes
how a graphic is drawn on your screen and nothing else.

## Settings

- **Halberd & scythe swings** - recolor the built-in swing trails (on by default).
- **Extra graphic IDs** - more graphics to recolor, comma separated.
- **Rainbow** - cycle through the rainbow, or turn off to use one fixed color.
- **Color speed (ms)** - how long one lap of the rainbow takes. Only used when Rainbow is on.
- **Custom color** - the color used when Rainbow is off. The game stores model colors in a small
  palette, so the shade you get is approximate.
- **Show graphic IDs** - prints the id of graphics that appear next to you in chat, to find the id of
  another weapon's swing. Turn it on, swing, read the id, add it to Extra graphic IDs, turn it off.
